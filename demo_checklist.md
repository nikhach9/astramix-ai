# AstraMix AI — Demo Readiness Checklist

This checklist verifies that the end-to-end user workflows, API integration, and mathematical solvers are fully ready for demonstrations and evaluations.

---

## 1. Local Setup Verification
- [ ] Start the backend server (`uvicorn app.main:app`) and verify it listens on `http://127.0.0.1:8000`.
- [ ] Open the interactive Swagger API documentation page at `http://127.0.0.1:8000/docs` to verify endpoints compile.
- [ ] Start the frontend next.js client (`npm run dev`) and verify it runs on `http://localhost:3000`.
- [ ] Verify the frontend console has no CORS blocking errors upon contacting the backend on start.

---

## 2. Core User Workflows

### A. Concrete Strength Prediction
- [ ] Navigate to the main dashboard or inputs panel.
- [ ] Enter a set of material quantities (e.g., Cement: 350 kg/m³, Water: 175 kg/m³, Coarse Aggregate: 1000 kg/m³, Fine Aggregate: 750 kg/m³, Superplasticizer: 5 kg/m³, Curing Age: 28 days).
- [ ] Click the **Predict/Calculate** action.
- [ ] **Verify**: A realistic predicted strength (in MPa) appears on screen.
- [ ] **Verify**: No backend exceptions occur (inspect logs/console).

### B. Environmental Impact (CO₂) Estimation
- [ ] Perform a strength prediction or update values.
- [ ] **Verify**: A CO₂ impact breakdown (total emissions in kg CO₂e/m³ and material breakdown) displays properly.
- [ ] **Verify**: The estimation matches values generated by the core package.

### C. Cost Estimation
- [ ] Perform a strength prediction or update values.
- [ ] **Verify**: A total estimated cost (per m³ with currency) displays.
- [ ] **Verify**: Individual material cost contribution breakdown appears.

### D. Mix Optimization
- [ ] Navigate to the optimization tab.
- [ ] Set a target strength (e.g., 40.0 MPa), age (28 days), and priority weights (alpha, beta).
- [ ] Click **Optimize Mix**.
- [ ] **Verify**: The optimized concrete recipe appears in < 1 second.
- [ ] **Verify**: If target is set to a highly impossible target (e.g., 150 MPa), the system returns HTTP 200 with `success: false` and explicit warning notes, rather than crashing or timing out.

---

## 3. Stability & Console Integrity
- [ ] Perform 10 consecutive optimization runs in the user interface.
- [ ] **Verify**: Next.js logs show no memory/connection hangs.
- [ ] **Verify**: The browser inspector console has 0 errors.
- [ ] **Verify**: No backend traceback/exception reports leak into response payloads or server logs.
- [ ] **Verify**: The session report data exports/saves successfully.
